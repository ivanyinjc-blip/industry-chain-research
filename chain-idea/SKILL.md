# chain-idea · 立项段

> 灵感:大刘《齐码.SKILL》vibe-idea 段
> 产物:`idea.md`(立项卡片)
> 输入:用户的模糊问题
> 输出:可被 chain-data 直接消费的 idea.md

## 🎯 这个 skill 干什么

把"想研究一下 XX"这种模糊念头,**挖成一份想清楚、还够狠的立项卡片**。

如果这一段没做清楚,后面 5 段都白做 — 因为边界没说清,数据/分析都会跑偏。

## 🧠 核心方法论:四度提问

大刘提出的「产品四度」,被我搬到产业链研究:

| 维度 | 做什么 | 在产业链中的对应问题 |
|---|---|---|
| **流变重构** | 颠覆性重构该行业的固有解法 | 这个环节如果用 AI / 新工艺 / 新材料,会不会整个重做? |
| **成本坍缩** | 边际成本快速下降 | 这个环节的成本是收敛还是发散? 摩尔定律是否适用? |
| **人即环境** | 用户深度参与/绑定 | 客户结构如何? 高粘性 vs 一客一议? |
| **可验证黑盒** | 输入输出可量化复现 | 这个公司的工艺/配方 能不能从财报 + 招股书复刻? |

任何一个行业,**至少在 2 个维度上立得住**,才算"还够狠的 idea"。

## 📐 11 词法 · 在产业链立项的体现

大刘的 11 个交互词,搬到产业链 = 11 个研究维度锁死语义:

| 大刘交互词 | 产业链研究对应 |
|---|---|
| navigate (跳转) | 这家公司主要走哪个应用场景(下游) |
| modal (弹窗) | 这个环节的"主要风险"环节是哪一个 |
| confirm (确认) | 这个增量来源是否"已确认/可能/未知" |
| drawer (抽屉) | 这个产品的"隐藏可变成本"在哪 |
| popover (气泡) | 这家公司的"差异化卖点"单点是什么 |
| bottomsheet (底部弹) | 行业"底部反转信号"出现没 |
| toast (提示) | 当前最值得短期跟踪的"事件"是哪个 |
| inline-expand (内联展开) | 这个环节的"价值量分布"具体怎么切 |
| inline-edit (内联编辑) | 这个环节有没有"成本结构变化"在发生 |
| newtab (新页) | 有没有"跨行业新需求"在打开 |
| download (下载) | 主要数据/资料「下载源」在哪(招股书/财报/行业协会) |

让"研究 XX"产生**确定性**,不留歧义。

## 🛠 工作流(可执行版)

```
输入: 用户的模糊问题("研究一下 AI 芯片吧")
  ↓
[Step 0: 口径拆分](借鉴 gushifenxi)
  拆 5 种可能的研究口径,选最可能的主口径继续分析
  - 大行业口径
  - 细分行业口径
  - 产业链自身口径(上中下游)
  - 下游应用口径
  - 市场预期口径
  ↓
[Step 1: 三问法]
  问 1: 痛感是什么? (谁在痛? 多痛? 多频?)
  问 2: 现有解法是什么? 痛在哪里?
  问 3: 最小可验证版本是啥? 怎么做算成功?
  ↓
[Step 2: 11 词法过滤]
  把模糊问题,套到 11 个词上 → 每个词至少给出一句答案
  ↓
[Step 3: 四度评分]
  流变重构 / 成本坍缩 / 人即环境 / 可验证黑盒 → 至少 2 个 ≥ 7 分
  ↓
[Step 4: 立项判定]
  ✅ 通过 → 输出 idea.md
  ❌ 不通过 → 必须先缩小范围或放弃
```

### Step 0 · 口径拆分细则

**为什么要先拆口径?** 一个词(如"氟化工")可以指整个行业,也可以指萤石资源、制冷剂、电子特气等细分环节,甚至可以指锂电池电解液中的应用。不同口径 = 不同研究边界 = 不同数据采集方向。

**5 种口径模板:**

| 口径类型 | 问自己 | 例子(氟化工) |
|---|---|---|
| 大行业 | 这是化工 / 材料 / 资源中的哪一类? | 氟化工属于精细化工 |
| 细分行业 | 哪个产品 / 材料 / 设备 / 工艺? | 萤石 / 氢氟酸 / 制冷剂 / 含氟聚合物 / 电子特气 |
| 产业链自身 | 拆上中下游,我们在哪一段? | 上游:萤石矿;中游:HF/制冷剂/PVDF;下游:空调/锂电/半导体 |
| 下游应用 | 主要被哪个下游用? | 制冷剂(空调) / PVDF(锂电粘结剂) / 电子级 HF(半导体) |
| 市场预期 | 市场上在交易什么? | 配额涨价 / 国产替代 / 固态电池拉动 / 半导体材料突破 |

**口径拆分表写入 idea.md**:

```markdown
## 0.5 口径拆分(借鉴 gushifenxi)

| 可能口径 | 说明 | 是否主口径 | 原因 | 数据状态 |
|---|---|---|---|---|
| 大行业 | | | | |
| 细分 | | | | |
| 产业链自身 | | | | |
| 下游应用 | | | | |
| 市场预期 | | | | |

**主口径选择**:[选哪个,为什么]
**不确定性标注**:[歧义是否影响结论,如影响则回头确认用户]
```

## 🚦 何时启用

- 用户首次提到某个产业链/公司/材料研究方向
- chain-data 上游缺失 idea.md
- chain-verify 发现"边界含糊,无法核销"时回查

## ⚠️ 红线

- ❌ 不准跳过"三问法" — 没有痛感的研究就是空中楼阁
- ❌ 不准"流变重构"得 0 分 — 缺颠覆性意义,这个产业链没有溢价机会
- ❌ 不准"成功标准"模糊 — 不可交付物必须明示
- ❌ 不准 idea.md > 100 行 — 立项超重,后面 5 段会跑偏

## 🔗 与下游的契约

- **给 chain-data**: idea.md 的"11 词过滤"表 + 立项边界 → 数据收集必须严格围绕这张表
- **给 chain-verify**: idea.md 的"成功标准" + "不可交付物" → 是核销清单的对照基线
- **不可改**: 立项一经确定,下游不能再改立项边界(除非专门走"立项变更申请")
