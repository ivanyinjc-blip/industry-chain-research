## 1. 三问法

### 1.1 痛感
- 谁在痛:中游光模块厂商在 800G 升级中卡脖子环节卡位不足;上游光芯片高度依赖海外(美日欧 >70%)
- 多痛:EML 芯片美日厂商占 90%+,VCSEL 国内刚突破,1.6T 时代可能断供风险
- 多频:技术代际 2-3 年一升级(100G→400G→800G→1.6T),错过窗口期致命

### 1.2 现有解法
- 现在怎么做:中游从旭创/新易盛主导(全球前 2),采购海外 II-VI/Lumentum/三菱的光芯片 + 自研模块
- 痛在哪:价值量集中在上游光芯片(EPS 高达 30-50% 毛利),中游模块商被博通/英伟达 GPU 客户砍价压利润

### 1.3 成功标准
- 研究交付物:8 段 pipeline 全部产物 + 选股清单
- 能回答的具体问题:
  1. 1.6T 升级周期中,谁是受益最大?
  2. 光芯片国产替代的 5-20% 阶段在哪几只股票?
  3. 当前周期位置:顶部/下降/底部/上升?
  4. 反向风险:美国对中国模块商的关税/限供风险?
- 不可交付物:具体目标价(target price) ;具体买入时机
