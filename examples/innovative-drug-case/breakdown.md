## 2. Top 4 深挖环节(评分 > 28)

### 2.1 上游试剂(填料/培养基)· 金矿环节 · ★★★★★ 最佳
**为什么是它:**
- 价值密度:60-80% 毛利率,堪比 IC 设计
- 市场增量:国产化率从 < 30% → 50% 加速替代中
- 可垄断性:Protein A 填料 Cytiva 垄断 90%,技术壁垒极高
- 可攻击性:纳微科技、奥浦迈、东富龙已突破
**缺口类型:国产替代 ★(0-5% → 5-20% 加速替代)**
**深挖路径:**
- 重点公司:纳微科技(688690)/奥浦迈(688293)/键凯科技(688356)
- 核心指标:填料市占率 / 客户名单(药明/百济/信达)/ 海外占比
**反证条件:**
- 如果 Cytiva 大幅降价(海外厂商反制),国产替代节奏被打断
- 如果 CXO 增速继续放缓,上游需求传导延迟

### 2.2 ADC 平台 · 金矿 + 颠覆环节 · ★★★★ 良好
**为什么是它:**
- 价值密度:科伦博泰与默沙东签 118 亿美元(单药首付款 8000 万 + 销售分成)
- 市场增量:全球 ADC 市场规模 2025 年 100 亿美元,2028 预计 300 亿
- 可垄断性:Linker/Payload 工艺 know-how 强,全球 ADC CDMO 仅 5 家(药明合联/科伦博泰/Lonza/Catalent/Seagen)
- 可攻击性:第三代 ADC(DXd / TROP2 / SKY)颠覆传统化疗
**缺口类型:新需求型(全球新增)**
**深挖路径:**
- 重点公司:科伦博泰(6990.HK)/药明合联(2268.HK)/信达(1801.HK)
- 核心指标:License-out 首付款 / 海外 III 期数据 / FDA 进度
**反证条件:**
- 如果默沙东撤回科伦博泰合作,ADC 估值杀
- 如果 ADC 临床失败率 > 60%,行业热度回落

### 2.3 GLP-1 减肥药 · 金矿 + 颠覆环节 · ★★★★ 良好
**为什么是它:**
- 价值密度:司美格鲁肽 2024 全球销售 400 亿美元,单药超过 PD-1 历史总和
- 市场增量:中国减肥市场 2025 仅 50 亿,2028 预计 500 亿(10 倍空间)
- 可垄断性:诺和/礼来全球双寡头,国内信达/恒瑞/联邦/甘李 追赶
- 可攻击性:口服 GLP-1 / 双靶点(GLP-1+GIP/GLP-1+胰高血糖素)重构减肥逻辑
**缺口类型:新需求型(全球新增 + 中国渗透率 < 5%)**
**深挖路径:**
- 重点公司:信达生物(1801.HK)玛仕度肽 / 联邦制药(3933.HK)UBT251 / 甘李药业(603087)
- 核心指标:玛仕度肽 NDA 进度 / 海外授权 / 减肥适应症获批
**反证条件:**
- 如果诺和/礼来专利诉讼成功,国产 GLP-1 出海受阻
- 如果 GLP-1 副作用(肌肉流失)被广泛报道,需求降温

### 2.4 核药(诊断+治疗)· 金矿环节 · ★★★★ 良好
**为什么是它:**
- 价值密度:东诚药业核药毛利率 70%+
- 市场增量:Pluvicto(诺华)2024 全球销售 14 亿美元,3 年 CAGR > 200%
- 可垄断性:放射性同位素生产需核反应堆,国内仅中国同辐/东诚双牌照
- 可攻击性:Lu-177 / Ac-225 治疗性核药颠覆传统化疗
**缺口类型:新需求型 + 国产替代**
**深挖路径:**
- 重点公司:东诚药业(002675)/中国同辐(1763.HK)
- 核心指标:Pluvicto 类似药进度 / Lu-177 国内获批 / 治疗性核药管线
**反证条件:**
- 如果核药医保谈判压价超预期,毛利率缩水
- 如果同位素进口受限,产能不足

## 3. 陪跑环节(一句话)

- **上游设备(反应器)**:周期下行 + 国产化 50%+,无显著缺口 → 配跑
- **CXO 国内(泰格/昭衍)**:医保压价 + 临床需求疲软 → 配跑
- **PD-1 同质化**:已过度内卷,医保压价到 3 万/年 → **规避**
- **仿制药 + 中药**:不在主口径 → 配跑
