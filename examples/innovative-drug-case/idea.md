## 1. 三问法

### 1.1 痛感
- **谁在痛**:
  - 中国创新药企:同质化内卷(PD-1 已从 60 万降到 3 万);出海受阻(美国生物安全法案阴影)
  - 上游试剂/耗材:CXO 增速放缓后,传导到上游(培养基/填料/一次性反应器)
  - CXO:海外订单(药明康德占 80%)受美国制裁担忧;国内订单(临床 CRO)被医保压价
  - 投资人:看不清"创新含量"+"出海能力"+"技术壁垒"三维的真实卡点
- **多痛**:
  - 2025 年 PD-1 出海遇阻,信达/百济/君实在美临床数据不达预期,股价 -40%
  - CXO 龙头药明康德 2024 年净利润同比 -20%,股价高点回撤 -60%
  - 培养基国产化率 < 30%(卡脖子),填料 < 10%(完全依赖 Cytiva/Tosoh)
- **多频**:
  - 政策:每季度(医保谈判/集采);月度(IND/NDA 申报);周度(BLA/获批)
  - 技术:年度(ASCO/ASH/ESMO 三大肿瘤年会)+ 半年度(ADA 糖尿病年会)
  - 资金:月度(港股 18A 募资规模/PE-PIPE 退出)

### 1.2 现有解法
- **现在怎么做**:
  - 投研:看 IND/NDA 数量 / 销售费用率 / 出海收入占比 / 管线进度
  - 选股:CXO 看海外占比 / 创新药看 ADC+GLP-1 双平台 / 上游看国产化率
- **痛在哪**:
  - 缺"卡点识别"维度:不区分"卡脖子的上游"和"被压价的中游"
  - 缺"政策周期"意识:医保谈判 + 美国生物安全法案 + DRG/DIP 三层政策叠加
  - 缺"出海能力"量化:License-out 首付款 / 海外 III 期数据 / FDA 进度

### 1.3 成功标准
- **研究交付物**:
  - 完整产出(idea → data → breakdown → cycle → analysis → report → verify → stockmap,v4.1+ 加 radar)
  - 数据卡 ≥ 60 行,数据点 ≥ 30 个
  - stockmap.md 至少 10 只候选股(覆盖 CXO / 创新药 / 上游试剂 3 类)
- **能回答的具体问题**:
  1. 创新药链上中下游 3 段的"价值量分布"和"卡点环节"分别是什么?
  2. 中国创新药"出海能力"的真实量化指标是什么?哪些公司已经跑通?
  3. 上游试剂耗材的"国产替代"已到哪一阶段?哪些环节是 5-20% 加速替代的"金矿"?
- **不可交付物**:
  - ❌ 不给具体投资标的的"目标价"和"买入区间"(违反 chain-stockmap 红线)
  - ❌ 不做"创新药全市场估值"(太散,聚焦卡点)
  - ❌ 不写"创新药基础知识科普"(目标读者是投研二级)

## 4. 周期 / 政策前置(本 skill 扩展 · 创新药专属)

### 4.1 周期位置
- **创新药板块**:从 2024 港股 18A 估值底(< 1×现金)+ 出海受阻,处于**底部反转初**
- **CXO 板块**:从 2022 高点回撤 60%+,处于**底部但未反转**(海外订单是关键)
- **上游试剂**:CXO 增速放缓传导,处于**下降末**(明年 CXO 复苏后反转)

### 4.2 政策环境
- **国内**:医保谈判常态化 + DRG/DIP 控费 + 创新药械鼓励(2026 商保创新药目录)
- **海外**:美国《生物安全法案》草案(2024 通过众议院)→ UVL 名单 → 限制 CXO 接单
- **港股**:18A 通道持续,但流动性差,需关注"以旧换新"机制
