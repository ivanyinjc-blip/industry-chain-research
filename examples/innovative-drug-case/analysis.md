## 环节 1 · 上游试剂(填料/培养基)· 国产替代 ★

### 1.1 成本层

**BOM(以 2000L 生物反应器为例):**
| 子项 | 单价 | 单位 | 占比 | 3 年变化 | 来源 |
|---|---|---|---|---|---|
| 培养基(CHO) | 800-1200 元/L | 反应体积 | 25-30% | -15%(国产替代) | 奥浦迈招股书 |
| 一次性反应器耗材 | 5000-8000 元/批 | 批次 | 15-20% | -10% | 洁特生物 |
| 填料(Protein A) | 3-5 万元/L | 柱体积 | 20-25% | -8%(纳微突破) | 纳微科技 |
| 纯化介质 | 2-4 万元/L | 柱体积 | 10-15% | -5% | 蓝晓科技 |
| 缓冲液 / 试剂 | 5-10% | 体积 | -5% | 键凯科技 |
| 滤膜 / 一次性管路 | 5-10% | 批次 | -3% | 洁特生物 |

**成本曲线:**
- 2020:海外厂商(Cytiva/默克)垄断,国产 < 5% 份额
- 2023:奥浦迈培养基突破 CHO 高密度培养,纳微填料进入百济/信达供应链
- 2026:国产化率突破 15%,成本 -15%(已核验:奥浦迈/纳微披露)
- 趋势:**降** ← 国产替代 + 工艺优化

**谁在挤压:**
- 海外厂商(Cytiva/默克)价格战降价 → 国产厂商利润空间压缩
- CXO 客户向上游传导成本压力 → 但国产厂商有 30-40% 毛利空间

### 1.2 利润层(借鉴 invest:微笑曲线 + 议价权)

**毛利分布(2025):**
- 上游试剂:**65-80%**(纳微 78% / 奥浦迈 70% / 键凯 70%)
- CXO:**35-45%**(药明 38% / 凯莱英 40%)
- 创新药:**70-90%**(毛利率)但**销售费用率 50%**吞掉利润

**微笑曲线定位:**
```
毛利率
  80%│  ● 上游试剂(60-80%)
     │    ● 创新药(70-90%,扣销售后净利<15%)
  40%│     ● CXO(35-45%)
     │      ● 仿制药(30-50%)
  10%│        ● 流通商业(5-10%)
     └──────────────────────────
       上游    中游     下游
```
- **上游试剂** = 利润吸盘(技术壁垒 + 客户粘性 + 高毛利)
- **CXO** = 利润中转站(规模优势但被压价)
- **创新药企** = 高毛利但被销售费用率吞噬

**议价权归属:**
- **谁有提价能力**:纳微(Protein A 填料国产突破)、奥浦迈(CHO 培养基高密度培养)
- **谁被动接受价格**:东富龙(反应器周期下行)、泰格(临床 CRO 被医保压价)

**利润转移方向:**
- 利润正在从 **CXO → 上游试剂** 转移(CXO 增速放缓 + 上游国产替代加速)
- 利润正在从 **PD-1 同质化 → ADC/GLP-1 新需求** 转移(医保谈判压价 PD-1 → ADC/GLP-1 议价权)

### 1.3 瓶颈层

**卡点:**
- **技术**:Protein A 填料载量 / 寿命(纳微仍在追赶 Cytiva MabSelect SuRe LX)
- **原料**:琼脂糖微球(纳微自产,但纯化级别仍受限)
- **设备**:高密度灌流培养(奥浦迈 50 g/L vs 默克 80 g/L)

**定价权归属:**
- **Cytiva**(被丹纳赫收购)垄断 Protein A 填料 90%
- **默克 / 赛默飞**垄断培养基 70%
- **国产厂商**(纳微/奥浦迈)正在打破 → 2026 国产化率 15-20%

### 1.4 供需验证

- 供给:2025 国内生物药产能 50 万升,新增 30%(在建项目)
- 需求:2025 国内生物药市场 6000 亿(CAGR 12%),新增灌流培养需求
- 缺口/富余:**试剂耗材**卡脖子环节仍紧缺(尤其 Protein A 填料),**反应器**富余

### 1.5 价值量定位

- ⭐ **价值集聚**(吸盘)
- 一句话:海外厂商卡脖子 + 国产替代加速 + CXO 增速放缓下"逆周期成长"

### 1.6 反证条件

- 如果 Cytiva 大幅降价(海外反制),国产替代节奏被打断
- 如果 CXO 增速继续放缓,上游需求传导延迟 1-2 年

## 环节 2 · ADC 平台 · 出海 + 技术双驱动

### 2.1 成本层

**BOM(以 ADC 单药为例):**
| 子项 | 单价 | 占比 | 来源 |
|---|---|---|---|
| 抗体(HER2/TROP2) | 50-150 万/kg | 35-40% | 药明生物 |
| Linker(DXd/MMAE) | 30-80 万/kg | 20-25% | Lonza |
| Payload(DXd/DM1) | 80-200 万/g | 25-30% | Catalent |
| 偶联工艺 | 10-15% | 药明合联 |
| 临床(III 期单药) | 5-8 亿 | 25-30% | CDE |

**成本曲线:**
- 第一代 ADC(2010):失败率 80%,单药成本 8 亿
- 第三代 ADC(2024):DS-8201 模式(DXd + 高 DAR + 旁观者效应),成本 5 亿,临床成功率 40%
- 趋势:**降**(第三代技术 + License-out 模式分摊研发成本)

### 2.2 利润层

**毛利分布(2025):**
- ADC 单药(成功):**85-95%** 毛利(DS-8201 全球销售 30 亿美元)
- ADC CDMO(药明合联):**40%** 毛利(YoY +90%)
- Linker/Payload 上游:**50-60%** 毛利(Lonza/Catalent 双寡头)

**议价权归属:**
- **DS-8201**(第一三共/阿斯利康):全球 ADC 龙头,定价权
- **科伦博泰**:与默沙东 118 亿美元合作,议价权提升
- **药明合联**:ADC CDMO 全球 5 家之一,议价权强

**利润转移方向:**
- 利润正在从 **小分子 CDMO(凯莱英)→ ADC CDMO(药明合联)** 转移(2024 凯莱英 -25% / 药明合联 +90%)
- 利润正在从 **传统化疗 → ADC + 双抗 + 核药** 转移(更精准的肿瘤治疗)

### 2.3 瓶颈层

**卡点:**
- **技术**:第三代 ADC 偶联工艺(DAR 控制 / 旁观者效应 / 稳定性)
- **原料**:Linker 与 Payload 的合成(国内 < 15% 国产化)
- **设备**:灌流偶联设备(国产已有突破)

**定价权归属:**
- **第一三共**(原研):DS-8201 全球第一,定价权绝对
- **Lonza / Catalent**:Linker/Payload 双寡头,议价权强
- **国内**(科伦博泰/药明合联):正在追赶,议价权逐步提升

### 2.4 供需验证

- 供给:全球获批 ADC 数量 15 个(2024),新增 5 个/年
- 需求:全球 ADC 市场 100 亿美元(2024),2028 预计 300 亿美元(CAGR 30%)
- 缺口/富余:**产能紧缺**(科伦博泰 / 药明合联均扩产中)

### 2.5 价值量定位

- ⭐ **价值集聚**(吸盘)+ **技术颠覆**
- 一句话:第三代 ADC 技术 + 出海 License-out 模式 + 全球新增需求

### 2.6 反证条件

- 如果默沙东撤回科伦博泰合作(临床失败),ADC 估值杀
- 如果 ADC 临床失败率 > 60%,行业热度回落
- 如果第三代 ADC 偶联工艺被国产突破,先发优势减弱

## 环节 3 · GLP-1 减肥药 · 全球爆款新需求

### 3.1 成本层

**BOM(以司美格鲁肽单剂量为例):**
| 子项 | 单价 | 占比 | 来源 |
|---|---|---|---|
| 多肽合成原料 | 200-400 元/支 | 10-15% | 联邦制药 |
| 制剂灌装 | 50-100 元/支 | 5-10% | 东富龙 |
| 临床(III 期单药) | 10-20 亿 | 40-50% | 诺和/礼来 |
| 销售(医生教育) | 销售额 30-50% | 20-30% | 诺和/礼来 |

**成本曲线:**
- 司美格鲁肽(2022 全球销售 100 亿美元,2024 400 亿美元)→ 边际成本极低
- 国产仿制(联邦/翰宇):原料 + 制剂成本下降 70%
- 趋势:**降**(规模效应 + 口服 GLP-1 突破)

### 3.2 利润层

**毛利分布(2025):**
- 诺和/礼来:**90%+** 毛利(全球定价权)
- 信达/联邦(国产):**60-70%** 毛利(中国市场 + 出海授权)
- 翰宇(原料):**40-50%** 毛利(原料供应商)

**议价权归属:**
- **诺和 / 礼来**:全球双寡头,定价权绝对(司美格鲁肽美国定价 1000 美元/月)
- **信达 / 联邦**:中国 + 出海,议价权逐步提升(玛仕度肽 IND 海外授权预期)
- **翰宇**(原料):诺和/礼来供应商,议价权中等

**利润转移方向:**
- 利润正在从 **糖尿病用药(二甲双胍)→ GLP-1(减肥)** 转移(全球爆款)
- 利润正在从 **注射剂 → 口服 GLP-1** 转移(诺和 Rybelsus / 礼来 orforglipron)

### 3.3 瓶颈层

**卡点:**
- **技术**:长效化修饰(PEG / Fc 融合 / 白蛋白融合)
- **原料**:多肽合成(国内已有突破,联邦/翰宇)
- **设备**:制剂灌装(国产东富龙已突破)

**定价权归属:**
- **诺和 / 礼来**:专利 + 全球品牌,定价权绝对
- **国产厂商**:中国市场份额 + 出海授权(议价权弱)

### 3.4 供需验证

- 供给:全球获批 GLP-1 数量 8 个(2024),新增 3 个/年
- 需求:全球 GLP-1 市场 600 亿美元(2024),2028 预计 1500 亿美元(CAGR 25%)
- 缺口/富余:**产能紧缺**(诺和/礼来均扩产,2026 仍供不应求)

### 3.5 价值量定位

- ⭐ **价值集聚**(吸盘)+ **新需求**
- 一句话:全球爆款新需求 + 中国渗透率 < 5% + 出海授权预期

### 3.6 反证条件

- 如果诺和/礼来专利诉讼成功,国产 GLP-1 出海受阻
- 如果 GLP-1 副作用(肌肉流失/甲状腺 C 细胞)被广泛报道,需求降温
- 如果口服 GLP-1 临床数据不及预期,注射剂估值杀

## 环节 4 · 核药(诊断+治疗)· 国产替代 + 新需求

### 4.1 成本层

**BOM(以 Lu-177 PSMA 治疗性核药为例):**
| 子项 | 单价 | 占比 | 来源 |
|---|---|---|---|
| Lu-177 同位素 | 5-10 万/剂 | 30-40% | 国际供应 |
| PSMA 配体 | 3-5 万/剂 | 20-25% | 东诚药业 |
| 标记 + 质控 | 1-2 万/剂 | 10-15% | 东诚药业 |
| 临床(III 期单药) | 5-8 亿 | 30-40% | CDE |
| 辐射防护 + 物流 | 5-10% | 中国同辐 |

**成本曲线:**
- Lu-177(2024 全球):诺华 Pluvicto 单剂 4 万美元,产能瓶颈
- 国内:东诚/同辐已有 Lu-177 在研,目标单剂 < 1 万人民币
- 趋势:**降**(国产化 + 产能扩张)

### 4.2 利润层

**毛利分布(2025):**
- 诺华 Pluvicto:**85%+** 毛利(全球第一)
- 东诚药业核药:**70%** 毛利(国内龙头)
- 中国同辐:**60%** 毛利(牌照壁垒)

**议价权归属:**
- **诺华**(Pluvicto 原研):全球定价权
- **东诚 / 同辐**:国内双牌照,议价权强
- **国内医院**:稀缺供给,议价权弱

**利润转移方向:**
- 利润正在从 **传统化疗 → 核药治疗** 转移(精准医疗)
- 利润正在从 **诊断核药(SPECT)→ 治疗核药(Lu-177 / Ac-225)** 转移

### 4.3 瓶颈层

**卡点:**
- **技术**:放射性同位素生产(需核反应堆,国内仅 2 座)
- **原料**:Lu-177 / Ac-225 进口依赖(美国 Curium / 俄罗斯)
- **设备**:辐射防护 + 冷链(同辐优势)

**定价权归属:**
- **诺华**(Pluvicto):全球第一,定价权绝对
- **东诚 / 同辐**:国内双牌照,议价权强
- **国内**:稀缺供给,议价权强

### 4.4 供需验证

- 供给:全球获批治疗性核药 5 个(2024),新增 2 个/年
- 需求:全球治疗性核药市场 50 亿美元(2024),2028 预计 150 亿美元(CAGR 30%)
- 缺口/富余:**产能紧缺**(诺华 Pluvicto 供不应求,东诚/同辐扩产中)

### 4.5 价值量定位

- ⭐ **价值集聚**(吸盘)+ **国产替代 + 新需求**
- 一句话:全球新增需求 + 国内双牌照 + 国产替代加速

### 4.6 反证条件

- 如果核药医保谈判压价超预期,毛利率缩水
- 如果 Lu-177 同位素进口受限,产能不足
- 如果放射性治疗副作用被广泛报道,需求降温

## 跨环节传导分析

### 假设 1: 美国《生物安全法案》参议院通过
- 传导路径:CXO 海外订单 ↓ → 上游试剂耗材需求 ↓ → 上游估值杀
- 终局:CXO 海外 -30%,上游试剂 -15%,但**创新药出海**(百济/科伦博泰)**不受影响**(已有获批药物)

### 假设 2: 商保创新药目录落地
- 传导路径:创新药企销售费用 ↓ → 利润 ↑ → 出海授权加速 → CXO + 上游受益
- 终局:创新药企 +10% 利润,CXO 国内订单 +20%,上游试剂 +15%

### 假设 3: ADC 临床失败率上升
- 传导路径:ADC 估值 ↓ → ADC CDMO(药明合联)估值 ↓ → Linker/Payload 估值 ↓
- 终局:ADC 板块 -25%,但 GLP-1 / 核药 / 上游试剂不受影响
