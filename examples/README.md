# industry-chain-research · 示例库

> 这里放完整的产业链研究样本,展示 9 段对齐架构(含 chain-cycle + chain-radar)的实战用法。

## 目录

- `ai-hbm-chain/idea.md` — AI 算力链(HBM + 光模块)立项示例(早期)
- **`pig-case/` — 猪肉养殖产业链完整 8 段样本(强周期 + chain-cycle,v3 历史快照)** ★ 标杆
- **`fluorine-case/` — 氟化工产业链完整 7 段样本(弱周期)** ★ 标杆

## 两案例对比学习

| 维度 | 氟化工 | 猪肉 | 意义 |
|---|---|---|---|
| 周期属性 | 弱周期(配额 + 涨价) | **强周期**(猪周期) | 验证 chain-cycle 的差异化处理 |
| 政策属性 | 中性 + 配额 | **强政策**(种业振兴) | 验证三角定位法 |
| 段数 | 7 段 | **9 段**(含 chain-cycle + chain-radar) | 强周期必跑 chain-cycle |
| Top 3 | 电子 HF / PVDF / 萤石 | 种猪 / 动保 / 智能养殖 | 都是"价值集聚" |
| 强烈推荐 | 4 只 | 4 只 | 都聚焦龙头 |
| 三角定位综合分 | 7.7(良好) | **9.3(最佳)** | 验证评级矩阵 |

## 用法

每个示例都对应"想研究 XX 产业链"的真实场景,展示 6/8/9 段 SKILL 的端到端用法。

**pig-case** 展示了:
1. chain-cycle 段的完整跑通(强周期行业必跑)
2. 「周期 × 缺口 × 政策」三角定位法的应用
3. 6 类周期指标的采集方法
4. 拐点预测 + 投资含义

**fluorine-case** 展示了:
1. 7 段弱周期行业的标准跑通
2. 三层价值量(成本/利润/瓶颈)+ 材料/设备/工艺三端
3. 数据状态分层(已核验/估算/预期/待查证)
4. 国产替代 5 阶段曲线

**对比学习** 两个案例能清晰看到 chain-cycle 的价值。
