## 2. Top 3 深挖环节(按总分排序)

### 2.1 电子级 HF(壁垒 + 金矿)· 国产替代型 + 卡脖子 ★★★
**为什么是它(总分 35/40):**
- 价值密度:50% 毛利,半导体级认证溢价(数据来自 data.md § 2.2)
- 市场增量:半导体国产化加速,需求年增 25%+
- 可垄断性:**半导体客户认证壁垒极高**,中芯/华虹认证周期 2-3 年
- 可攻击性:多氟多/中欣已突破,正在快速国产替代

**缺口类型(借鉴 invest):**
- 国产替代型(卡脖子子类型):半导体级 HF 国产化率 < 20%,被卡
- 增量型:半导体扩产周期带动需求

**深挖路径:**
- 分析公司:多氟多(002407) + 中欣氟材(002915) + 雅克科技(002409)
- 看哪几个核心指标:半导体客户数 / 单客户采购量 / 良率 / 价格

**反证条件(预判):**
- 如果 [半导体扩产周期推迟],国产替代节奏放缓
- 如果 [海外大厂(日本 Stella/法国 Air Liquide)大幅扩产],价格战风险
- 如果 [中芯国际转向非 HF 工艺],需求结构性下降

### 2.2 PVDF 锂电级(金矿 + 颠覆)· 国产替代型 + 新需求型 ★★★
**为什么是它(总分 31/40):**
- 价值密度:35% 毛利,锂电粘结剂刚需(数据来自 data.md § 2.2)
- 市场增量:新能源车 + 储能双轮,CAGR > 30%
- 可垄断性:**锂电客户认证 + 长协绑定**,宁德/比亚迪订单可见度 2 年
- 可攻击性:**固态电池替代风险**(但短期不可替代,长期需跟踪)

**缺口类型(借鉴 invest):**
- 国产替代型:锂电级 PVDF 国产化率 < 30%,正在加速(20-50% ★ 阶段)
- 新需求型:固态电池对 LiPF6/LiFSI 拉动,新工艺

**深挖路径:**
- 分析公司:东岳集团(0189.HK) + 巨化股份(600160) + 三爱富(600636)
- 看哪几个核心指标:锂电客户数 / 单 GWh 用量 / 良率 / 价格

**反证条件(预判):**
- 如果 [固态电池量产提前],PVDF 需求断崖
- 如果 [R142b 配额大幅放开],中游成本下降,壁垒削弱
- 如果 [海外大厂(法国阿科玛/日本吴羽)大幅降价],国产替代溢价消失

### 2.3 萤石资源(金矿)· 瓶颈型 + 卡脖子 ★★
**为什么是它(总分 28/40):**
- 价值密度:65% 毛利,资源稀缺性溢价(数据来自 data.md § 2.2)
- 市场增量:需求增长 5%,但**资源端供给受限**
- 可垄断性:**战略资源 + 出口管制**,开采配额受国家控制
- 可攻击性:无替代资源(萤石 = 氟的唯一工业来源)

**缺口类型(借鉴 invest):**
- 瓶颈型:资源紧缺 + 扩产周期 5+ 年
- 卡脖子(子类型):氟的"石油级"战略地位

**深挖路径:**
- 分析公司:金石资源(603505) + 巨化股份(600160) + 中欣氟材(002915)
- 看哪几个核心指标:萤石储量 / 产能 / 出口配额 / 单吨成本

**反证条件(预判):**
- 如果 [海外萤石矿(墨西哥/南非)大幅扩产],资源溢价消失
- 如果 [磷酸提氟替代技术突破],氟的来源分散
- 如果 [国内开采配额大幅放开],供给冲击

## 3. 陪跑环节(一句话)

- **HF 中间体**:壁垒中等,跟随上游萤石价格波动,无独立 alpha
- **制冷剂(R32/134a)**:配额制带来波动,但增长空间有限,行业 beta
- **含氟聚合物(其他)**:分散应用,无明显卡位
- **三废处理设备**:配套环节,跟氟化工扩产同步
