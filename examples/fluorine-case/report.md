## 摘要

氟化工是化工领域典型的"**卡点 + 国产替代 + 新材料新需求**"三类机会叠加的产业链。本文研究三大最具 alpha 的环节:**电子级 HF(PV/半导体)**、**PVDF 锂电级(锂电池)**、**萤石资源(战略基石)**,并映射到具体上市公司股票清单。

**核心结论:**
1. 电子级 HF 是**最紧迫的国产替代卡点**:半导体客户认证壁垒极高,国产化率 < 20%,多氟多/中欣氟材已突破中芯国际认证
2. PVDF 锂电级是**最快增长的环节**:锂电 + 储能双轮驱动 + 国产替代 20-50% 加速阶段,东岳/巨化/三爱富直接受益
3. 萤石资源是**战略基石**:氟的"石油级"战略资源 + 出口管制,金石资源 + 巨化股份拥有稀缺储量

**最大风险:**固态电池量产提前 → PVDF 需求断崖;海外大厂大幅降价 → 国产替代溢价消失。

## 1. 开场 · 为什么研究氟化工

### 1.1 3 个具体问题

1. 氟化工产业链上,**哪些环节存在卡点 / 国产替代 / 新材料新需求**?
2. 这些环节里,**哪些上市公司的卡位最有 alpha**?
3. 主要风险点是什么,如何跟踪?

### 1.2 我们的回答

1. 三类缺口并存:**卡点(萤石+电子 HF 卡脖子)**、**国产替代(电子 HF+PVDF 双线)**、**新需求(固态电池 LiFSI)**
2. **多氟多(电子 HF + LiFSI 双卡位)/ 东岳集团(PVDF 龙头) / 金石资源(萤石龙头)** 三只是核心标的
3. 风险:**固态电池量产 + 海外大厂降价 + 配额政策变化**,通过月度跟踪机制监控

## 2. 拆链 · 整体框架

### 2.1 上中下游全景(材料/设备/技术工艺三端)

```
上游                          中游                           下游
┌──────────────┐              ┌──────────────────┐           ┌──────────────┐
│ 萤石资源(卡)  │────→       │ HF → 制冷剂        │────→    │ 空调(美的/格力)│
│ 萤石精粉(高纯)│              │ HF → PVDF(锂电级)  │           │              │
│              │              │ HF → 电子级 HF     │           │ 锂电(宁德/比亚迪)│
│ 设备(精馏塔) │────→       │ HF → 含氟聚合物    │────→    │ 半导体(中芯/华虹)│
│ 设备(检测仪器)│              │ HF → 锂盐(LiFSI)  │           │              │
│ 工艺(电子级) │────→       │                   │           │ 医药/农药      │
└──────────────┘              └──────────────────┘           └──────────────┘
```

### 2.2 三层价值量总览(借鉴 gushifenxi 三端拆解)

| 端口 | 成本价值量 | 利润价值量 | 瓶颈价值量 | 关键判断 |
|---|---|---|---|---|
| 材料端(萤石) | 普通占比 | **高(65%)** | **高(战略资源)** | **卡脖子资源** |
| 设备端(精馏塔+检测) | 中 | 中 | **高(扩产瓶颈)** | 关键设备 |
| 技术工艺端(电子级 HF 工艺) | 不直接体现 | **高(认证溢价)** | **高(良率+认证)** | 核心 know-how |

> 关键提醒:萤石成本占比 30% 但**不是高价值环节**;真正高价值的是**资源稀缺性(战略)+ 工艺 know-how(认证)**。

## 3. 聚焦 · Top 3 环节深挖

### 3.1 环节 A · 电子级 HF(国产替代 + 卡脖子)★★★

#### 3.1.1 成本层
| 子项 | 单价 | 单位 | 占比 | 3 年变化 | 数据状态 |
|---|---|---|---|---|---|
| 高纯萤石粉 | 4500 | 元/吨 | 35% | +25% | 已核验 |
| 硫酸 | 800 | 元/吨 | 10% | +5% | 已核验 |
| 精馏能耗 | - | - | 25% | -10% | 估算 |
| 三废处理 | - | - | 15% | +10% | 估算 |
| 检测认证 | - | - | 10% | +20% | 待查证 |

#### 3.1.2 利润层
- **毛利分布**:电子级 HF 50% vs 工业级 HF 25%(认证溢价)
- **议价权**:多氟多掌握定价权(中芯国际认证 + 良率稳定)
- **利润转移方向**:工业级 HF → 电子级 HF(认证壁垒加高)

#### 3.1.3 瓶颈层
- 技术:**金属杂质控制(< 10ppb)** + 颗粒控制(< 0.1μm)
- 设备:**痕量金属检测设备国产化率 < 30%**
- 客户:中芯/华虹认证周期 2-3 年

#### 3.1.4 差异化卖点(popover)
电子级 HF vs 工业级 HF 价差 5000 元/吨。数据来源 [多氟多 2025 年报]。

#### 3.1.5 隐藏成本(drawer)
三废处理 + 检测认证成本年增 10-20%,但终端价格涨幅跟不上,挤压毛利。数据来源 [估算]。

#### 3.1.6 成本变化(inline-edit)
2022 年成本 8500 元/吨 → 2026 年 11000 元/吨,3 年累计 +29%(萤石涨价 + 检测加严)。

#### 3.1.7 价值量分布(inline-expand)
- 萤石占 BOM 35%(成本端)
- 精馏工艺占 BOM 25%(成本端)
- **认证溢价占售价 20%**(利润端)

### 3.2 环节 B · PVDF 锂电级(国产替代 + 新需求)★★★

#### 3.2.1 成本层
| 子项 | 单价 | 单位 | 占比 | 3 年变化 | 数据状态 |
|---|---|---|---|---|---|
| 萤石精粉 | 3200 | 元/吨 | 25% | +20% | 已核验 |
| 无水 HF | 9500 | 元/吨 | 20% | +15% | 已核验 |
| R142b(VDF 原料) | 38000 | 元/吨 | 40% | +50% | 已核验 |
| 聚合能耗 | - | - | 10% | -5% | 估算 |

#### 3.2.2 利润层
- **毛利分布**:锂电级 PVDF 35% vs 工业级 PVDF 20%
- **议价权**:东岳/巨化掌握(宁德/比亚迪长协)
- **利润转移**:工业级 → 锂电级(认证溢价)

#### 3.2.3 瓶颈层
- 技术:锂电级分子量分布控制 + 共聚工艺
- 原料:**R142b 配额**(政策强约束)
- 客户:宁德/比亚迪认证周期 1-2 年

#### 3.2.4 差异化卖点
锂电级 vs 工业级 PVDF 价差 15000 元/吨。数据来源 [锂电协会 2025]。

#### 3.2.5 隐藏成本
R142b 配额收紧,原料涨价 50%,但 PVDF 终端价格涨幅有限,毛利受挤压。

#### 3.2.6 成本变化
2022 年 28000 元/吨 → 2026 年 45000 元/吨,+61%(R142b 配额 + 萤石)。

#### 3.2.7 价值量分布
- R142b 占 BOM 40%(成本端,配额决定)
- 认证溢价占售价 25%(利润端)

## 5. 结论 · 可行动的话

### 5.1 给三类读者的建议

**给投资者:**
- **核心标的**:多氟多(002407,电子 HF + LiFSI 双卡位)/ 东岳集团(0189.HK,PVDF 龙头)/ 金石资源(603505,萤石龙头)
- **次选标的**:巨化股份(600160,一体化氟化工龙头)/ 中欣氟材(002915,电子 HF 第二梯队)
- **观察标的**:三美股份(603379,制冷剂 + PVDF)/ 昊华科技(600378,电子特气)

**给从业者:**
- 上游萤石资源是不可复制的战略资产,长期持有
- 电子级 HF 工艺 know-how 是核心壁垒,3 年内不会被颠覆
- PVDF 锂电级窗口期 2-3 年,扩产需谨慎

**给研究者:**
- 持续跟踪**固态电池量产时间表**(对 PVDF 是颠覆性)
- 持续跟踪**R142b 配额政策**(影响 PVDF 成本)
- 持续跟踪**半导体国产化率**(电子 HF 需求弹性)

### 5.2 短期跟踪事件(toast)

- **2026-07-15**:多氟多 Q2 业绩预告
- **2026-08-30**:东岳集团中期业绩
- **2026-10-25**:巨化股份 Q3 财报
- **2026-Q4**:R142b 配额年度调整

### 5.3 跨行业新需求(newtab)

- **固态电池 LiPF6/LiFSI**:多氟多已布局,2027 年起放量
- **钠电池电解液**:氟盐作为关键组分,新需求
- **半导体先进制程**:电子级 HF 用量随制程升级提升

## 附录 C · 术语表

- **HF**:氢氟酸,氟化工基础原料
- **PVDF**:聚偏氟乙烯,含氟聚合物
- **R142b**:1-氯-1,1-二氟乙烷,PVDF 关键原料,受蒙特利尔议定书配额管制
- **VDF**:偏氟乙烯,PVDF 单体

- **10ppb**:十亿分之一浓度,半导体级 HF 杂质控制标准
