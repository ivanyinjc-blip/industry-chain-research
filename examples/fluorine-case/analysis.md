### 2.3 瓶颈层

- 技术:锂电级 PVDF 分子量分布控制 + 共聚工艺

- 一句话定位:"锂电 + 储能双轮驱动 + 国产替代 20-50% 加速阶段,PVDF 是氟化工产业链上**最快增长环节**"

### 2.6 反证条件
- 如果 [固态电池量产提前 1 年+],PVDF 需求断崖式下降

## 跨环节传导分析

### 假设 1:萤石涨价 20%
- 传导路径:萤石 → HF → PVDF/制冷剂 → 锂电池/半导体
- 各环节吸收比例:HF 厂吸收 5% / PVDF 厂吸收 8% / 制冷剂厂吸收 10%
- 终局:**PVDF 终端涨价 8-10% / 制冷剂终端涨价 5-8%**

### 假设 2:半导体级 HF 国产替代加速
- 传导路径:电子 HF 国产化 → 多氟多/中欣扩产 → 萤石资源紧张
- 终局:**萤石资源端进一步紧平衡,价格中枢上移**

### 假设 3:固态电池量产提前
- 传导路径:固态电池 → LiPF6/LiFSI 替代 PVDF → PVDF 需求断崖
- 终局:**PVDF 国产替代窗口缩短,估值压缩**

### 假设 4:R142b 配额放开
- 传导路径:R142b 涨价缓解 → PVDF 成本下降 → 中游壁垒削弱
- 终局:**国产替代溢价消失,行业回到成本竞争**
