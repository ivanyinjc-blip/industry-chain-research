## 1. 三问法

### 1.1 痛感
- 谁在痛:**二级市场投资者** + 氟化工产业链上中下游企业
- 多痛:萤石资源稀缺(战略资源) / 高端电子特气卡脖子 / PVDF 在锂电 + 半导体双线拉动
- 多频:**每季度配额调整** / **每年新能源车销量** / **实时萤石价格**

### 1.2 现有解法
- 现在怎么做:萤石资源端(巨化/三美/永和/昊华);HF 中间体(巨化/三美);制冷剂配额(2024 基线);PVDF(东岳/巨化/三爱富);电子级 HF(多氟多/雅克)
- 痛在哪:
  1. 萤石:**战略资源 + 出口管制**,资源端卡脖子
  2. 电子特气:**半导体级 HF 国产化率 < 20%**,被卡
  3. PVDF:**锂电池级 PVDF 国产化率 < 30%**,但锂电粘结剂刚需
  4. 制冷剂:**配额制导致 R142b 价格波动剧烈**,影响 PVDF 上游

### 1.3 成功标准
- 研究交付物:
  - 7 段 pipeline 完整跑通(idea/data/breakdown/analysis/report/verify/stockmap)
  - 产出氟化工研报 8000 字 + 选股清单 5-8 只
- 能回答的具体问题:
  1. 氟化工产业链上,**哪 3 个环节是真有 alpha**?
  2. **萤石 / 电子特气 / PVDF** 三个缺口,谁最紧迫?
  3. 主要风险点是什么,如何跟踪?
- 不可交付物:
  - 不做个股择时
  - 不做衍生品策略
  - 不做短期价格预测
