## 1. 三问法

### 1.1 痛感
- 谁在痛:**二级市场投资者** + 猪肉产业链上中下游企业 + 消费者
- 多痛:猪周期波动剧烈(单年涨跌 50%+);非洲猪瘟反复;种猪 90% 依赖进口;豆粕价格波动
- 多频:**每季度能繁母猪存栏** / **每周猪价** / **每年进口种猪数据**

### 1.2 现有解法
- 现在怎么做:
  - 上游:种猪(丹系/法系进口为主);饲料(豆粕 + 玉米);动保(疫苗 + 兽药)
  - 中游:牧原/温氏/新希望为代表的大规模养殖
  - 下游:双汇/雨润屠宰加工 + 顺丰/京东冷链
- 痛在哪:
  1. **种猪卡脖子**:原种猪 90% 进口,白系/丹系/法系垄断
  2. **豆粕依赖**:大豆 85% 进口,饲料成本被外部卡
  3. **非洲猪瘟防控**:生物安全水平参差不齐
  4. **猪周期波动**:散户为主,产能去化慢

### 1.3 成功标准
- 研究交付物:
  - 7 段 pipeline 完整跑通
  - 产出猪肉研报 + 选股清单
- 能回答的具体问题:
  1. **猪周期当前位置**?反转预期还是周期顶部?
  2. **种猪国产替代**真实进展?
  3. **非洲猪瘟防控**谁是真正的赢家?
  4. 主要风险点是什么,如何跟踪?
- 不可交付物:
  - 不做短期猪价预测
  - 不做个股择时
