## 2. Top 3 深挖环节(按总分排序)

### 2.1 种猪育种(壁垒 + 金矿)· 卡脖子 + 国产替代 + 新需求 ★★★
**为什么是它(总分 34/40):**
- 价值密度:50% 毛利,育种 know-how 溢价
- 市场增量:育种国产替代,国家战略(种业振兴行动)
- 可垄断性:**育种周期 5+ 年**,头部企业领先,门槛极高
- 可攻击性:基因育种 + 胚胎技术是新工艺

**缺口类型(借鉴 invest):**
- 卡脖子型:原种猪 90% 进口(丹系/法系/美系)
- 国产替代型:国家"种业振兴"政策驱动
- 新需求型:育种效率(PSY)提升是新工艺方向

**深挖路径:**
- 分析公司:牧原股份(002714) / 温氏股份(300498) / 新希望(000876) / 大北农(002385)
- 看哪几个核心指标:PSY(每头母猪年提供断奶仔猪)/ MSY / 育种体系完整度

**反证条件(预判):**
- 如果 [海外种猪企业大举进入中国],国产育种窗口关闭
- 如果 [非洲猪瘟再次大规模爆发],育种体系崩溃
- 如果 [国家种业政策转向],投入减少

### 2.2 动保(疫苗+兽药)(壁垒)· 国产替代 ★★
**为什么是它(总分 29/40):**
- 价值密度:65% 毛利,牌照壁垒
- 市场增量:非洲猪瘟疫苗仍在研发 + 蓝耳病等疫苗刚需
- 可垄断性:**疫苗牌照 + 研发周期长**,CR3 > 50%
- 可攻击性:基因工程疫苗 + mRNA 疫苗是新工艺

**缺口类型:**
- 国产替代型:动保国产化率 70%+,但高端疫苗仍依赖进口
- 新需求型:非洲猪瘟疫苗 + 蓝耳病疫苗

**深挖路径:**
- 分析公司:科前生物(688526) / 生物股份(600201) / 普莱柯(603566)
- 看哪几个核心指标:疫苗品种 / 市场份额 / 研发投入

**反证条件(预判):**
- 如果 [非洲猪瘟疫苗研发失败],动保企业估值压缩
- 如果 [海外动保巨头(勃林格/默沙东)大举降价],国产替代溢价消失

### 2.3 智能养殖设备(颠覆)· 新需求型 ★
**为什么是它(总分 27/40):**
- 价值密度:中,但成长性高
- 市场增量:AI + IoT 推动,2025-2028 CAGR 25%+
- 可垄断性:中等,头部企业领先
- 可攻击性:**AI + 智能是新工艺方向**,颠覆传统养殖

**缺口类型:**
- 新需求型:AI 养殖是新工艺方向

**深挖路径:**
- 分析公司:牧原(自研设备) / 影子科技(未上市) / 京基智农(000048)
- 看哪几个核心指标:智能设备渗透率 / PSY 提升 / 人工成本下降

**反证条件(预判):**
- 如果 [智能设备成本下降不及预期],渗透率停滞
- 如果 [散户快速退出不及预期],规模养殖场增量受限

## 3. 陪跑环节(一句话)

- **饲料原料(玉米+豆粕)**:大宗属性,跟随农产品价格波动,无独立 alpha
- **饲料加工**:海大/大北农主导,但同质化竞争
- **中小养殖户**:散户快速退出,长期陪跑
- **屠宰加工**:双汇主导,品牌壁垒,但增长空间有限
- **冷链物流**:顺丰/京东主导,跟随电商和肉制品需求
