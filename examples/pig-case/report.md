## 摘要

猪肉是中国最大的肉类消费品,**猪周期波动剧烈**让产业链充满机会与风险。本文研究三大最具 alpha 的环节:**种猪育种(国家战略)、动保(牌照壁垒)、智能养殖设备(AI 颠覆)**,并映射到具体上市公司股票清单。

**核心结论:**
1. **种猪育种是最稀缺的战略资产**:原种猪 90% 进口 + 国家"种业振兴"战略 + 育种 know-how 不可复制,牧原/温氏/新希望直接受益
2. **动保是最具壁垒的细分**:疫苗牌照强约束 + 非洲猪瘟疫苗研发竞赛,科前生物/生物股份有先发优势
3. **智能养殖设备是最具颠覆性的新工艺**:AI + IoT 推动,2025-2028 CAGR 25%+,牧原自研领先

**最大风险:**猪周期反转不及预期 + 非洲猪瘟再次大规模爆发 + 海外种猪企业进入

## 1. 开场 · 为什么研究猪肉产业链

### 1.1 3 个具体问题

1. 猪肉产业链上,**哪些环节存在卡点 / 国产替代 / 新材料新需求**?
2. **种猪 / 动保 / 智能养殖**三个 Top 3 环节,谁最紧迫?
3. 主要风险点是什么,如何跟踪?

### 1.2 我们的回答

1. 三类缺口并存:**卡点(种猪 + 大豆)、国产替代(种猪 + 动保)、新需求(智能养殖)**
2. **种猪育种最紧迫**(国家战略 + 进口 90%);**动保最具壁垒**(牌照);**智能养殖最具颠覆性**(AI)
3. 风险:**猪周期反转 + 非瘟 + 海外种猪企业进入**,通过月度跟踪机制监控

## 2. 拆链 · 整体框架

### 2.1 上中下游全景

```
上游                          中游                  下游
┌──────────────┐              ┌──────────────┐       ┌──────────────┐
│ 种猪(卡脖子)  │              │              │       │ 屠宰加工     │
│ 饲料原料(大豆)│────→       │ 大规模养殖    │────→ │ 肉制品深加工 │
│ 动保(疫苗)   │              │ (牧原/温氏)   │       │ 冷链物流     │
│ 智能设备     │              │              │       │              │
└──────────────┘              └──────────────┘       └──────────────┘
```

### 2.2 三层价值量总览(借鉴 gushifenxi)

| 端口 | 成本价值量 | 利润价值量 | 瓶颈价值量 | 关键判断 |
|---|---|---|---|---|
| 材料端(种猪+饲料) | **高(60%)** | 中 | **高(种猪卡脖子)** | 种猪=核心卡点 |
| 设备端(智能养殖) | 中 | 低 | 中(国产化中) | 关键设备国产替代中 |
| 技术工艺端(育种+防控) | 不直接体现 | **高(50%+ 毛利)** | **高(核心 know-how)** | 育种 know-how 是核心 |

> 关键提醒:饲料成本占比 60% 但**不是高价值环节**(大宗属性);**种猪 + 育种 know-how**才是真正的卡点 + 利润吸盘。

## 3. 聚焦 · Top 3 环节深挖

### 3.1 环节 A · 种猪育种(壁垒 + 金矿)★★★

#### 3.1.1 成本层
| 子项 | 单价 | 单位 | 占比 | 3 年变化 | 数据状态 |
|---|---|---|---|---|---|
| 饲料 | 2800 | 元/吨 | 55% | -10% | 已核验 |
| 动保 | - | - | 10% | +5% | 估算 |
| 人工 + 折旧 | - | - | 20% | +8% | 估算 |
| 环保 | - | - | 10% | +15% | 估算 |

#### 3.1.2 利润层
- **毛利分布**:种猪育种 50%+ / 商品代仔猪 25%
- **议价权**:牧原/温氏掌握(自育种猪)
- **利润转移**:中小养殖户 → 种猪育种龙头(散户退出 + 集中度提升)

#### 3.1.3 瓶颈层
- 育种周期 5+ 年,know-how 沉淀
- 原种猪 90% 进口(丹/法/美系)
- 国家"种业振兴行动"政策窗口

#### 3.1.4 差异化卖点(popover)
PSY 28 vs 行业平均 22。数据来源 [牧原/温氏 2025 年报]。

#### 3.1.5 隐藏成本(drawer)
环保处理 + 病死猪无害化成本年增 15%,挤压毛利。数据来源 [估算]。

#### 3.1.6 成本变化(inline-edit)
2022 年 4500 元/头 → 2026 年 5000 元/头,+11%(环保 + 人工 + 动保)。

#### 3.1.7 价值量分布(inline-expand)
- 饲料占成本 55%(成本端,大宗属性)
- **育种 know-how 占售价 25%**(利润端,核心)

### 3.2 环节 B · 动保(壁垒)· 国产替代 + 新需求 ★★

#### 3.2.2 利润层

- **利润转移**:中小动保 → 头部国产动保

#### 3.2.3 瓶颈层
- 疫苗生产牌照强约束

## 5. 结论 · 可行动的话

### 5.1 给三类读者的建议

**给投资者:**
- **核心标的**:牧原股份(002714,种猪+养殖双龙头) / 温氏股份(300498,种猪育种领先) / 科前生物(688526,动保龙头)
- **次选标的**:新希望(000876,种猪+饲料一体化) / 生物股份(600201,口蹄疫疫苗龙头) / 大北农(002385,种业+饲料)
- **观察标的**:京基智农(000048,智能养殖) / 唐人神(002567,饲料+养殖)
- **猪周期判断**:能繁母猪 3900 万头接近底部,但反转时点不确定,建议左侧布局种猪 + 动保(独立于猪周期)

**给从业者:**
- **种猪育种是不可复制的战略资产**,长期持有
- **动保疫苗牌照是新进入者的高墙**,头部企业护城河深
- **智能养殖设备是 3-5 年的新工艺方向**

**给研究者:**
- 持续跟踪**能繁母猪存栏**(猪周期核心指标)
- 持续跟踪**非洲猪瘟疫苗研发进展**(动保关键变量)
- 持续跟踪**国家种业振兴政策**(种猪育种政策红利)
