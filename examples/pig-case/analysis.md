## 环节 1 · 种猪育种(壁垒 + 金矿)· 卡脖子 + 国产替代 + 新需求

### 1.1 成本层
**BOM(以一头母猪年成本为例):**
| 子项 | 单价 | 单位 | 占比 | 3 年变化 | 来源 | 数据状态 |
|---|---|---|---|---|---|---|
| 饲料(妊娠+哺乳) | 2800 | 元/吨 | 55% | -10% | 博亚和讯 | 已核验 |
| 动保(疫苗+兽药) | - | - | 10% | +5% | 行业协会 | 估算 |
| 人工 + 折旧 | - | - | 20% | +8% | 估算 | 估算 |
| 环保 + 粪污处理 | - | - | 10% | +15% | 估算 | 估算 |
| 其他 | - | - | 5% | - | - | - |

**成本曲线:**
- 2022:年成本 4500 元/头
- 2024:年成本 4800 元/头(+7%)
- 2026:年成本 5000 元/头(预估 +4%)
- 趋势:**升**(环保 + 人工 + 动保)

**谁在挤压:**
- 饲料价格波动小,但环保和人工成本持续上升
- 进口种猪涨价 30%(汇率 + 国际航运)

### 1.2 利润层(借鉴 invest:微笑曲线 + 议价权)

**毛利分布:**
- 上游(原种猪育种):50%+ — 牧原/温氏自育种猪
- 中游(商品代仔猪):25% — 周期波动大
- 下游(育肥猪):周期波动,2024 年微亏,2026 年微利

**溢价能力:**
- 自育种猪 PSY 28 vs 行业平均 22 — 龙头溢价
- 育种 know-how 不可复制,议价权集中

**微笑曲线定位:**
```
利润率
  高│  种猪育种        肉制品深加工
    │    ●               ●
    │     ●             ●
    │      ●  商品代   ●
    │       ●●●●●●●●●
  低│        ●●●●●●●●●
    └──────────────────────────
      上游          中游          下游
```
- 本环节位置:**左高(育种 know-how)**
- 利润正在从 [中小养殖户] → [种猪育种龙头] 集中

**议价权归属:**
- 谁有提价能力:**牧原/温氏**,原因(自育种猪 + 规模)
- 谁在被动接受价格:**中小养殖户**,原因(无育种能力)
- 涨价能否传导:**部分传导**(周期高点可,低点难)

**利润转移方向:**
- 利润正在从 [商品代养殖] → [种猪育种] 转移
- 原因:散户快速退出 + 育种 know-how 集中

### 1.3 瓶颈层
**卡点:**
- 育种:**育种周期 5+ 年**,know-how 沉淀
- 原种:**90% 进口**(丹系/法系/美系),受国际供应影响
- 政策:国家"种业振兴行动"政策窗口期
- 非洲猪瘟:**生物安全等级 A 级**是核心竞争力

**定价权归属:**
- **牧原股份** 掌握 [自育种猪] 定价权,原因:育种体系完整 + 规模优势
- **温氏股份** 掌握 [丹系种猪] 定价权,原因:PSY 行业领先

### 1.4 供需验证
- 供给:国内种猪存栏 [约 100 万头],但原种猪进口占比 90%
- 需求:年生猪出栏 [约 7 亿头],种猪需求稳定
- 缺口/富余:**原种猪 100% 依赖进口,国产替代空间巨大**

### 1.5 价值量定位
- ⭐ **价值集聚(育种 know-how + 国产替代窗口)**
- 一句话定位:"原种猪 90% 进口 + 国家'种业振兴'战略 + 育种 know-how 不可复制,**种猪育种是猪肉产业链上最稀缺的战略资产**"

### 1.6 反证条件
- 如果 [海外种猪企业大举进入中国],国产育种窗口关闭
- 如果 [非洲猪瘟再次大规模爆发],育种体系崩溃
- 如果 [国家种业政策转向],投入减少
- 如果 [PSY 提升遇到生物学天花板],know-how 价值下降

## 环节 2 · 动保(壁垒)· 国产替代 + 新需求

### 2.1 成本层
**BOM(以猪用疫苗为例):**
| 子项 | 单位 | 占比 | 3 年变化 | 来源 | 数据状态 |
|---|---|---|---|---|---|
| 研发(菌种+工艺) | - | 30% | +20% | 估算 | 估算 |
| 生产(培养基+设备) | - | 35% | +5% | 估算 | 估算 |
| 销售 + 推广 | - | 20% | +10% | 估算 | 估算 |
| 监管 + 认证 | - | 10% | +5% | 估算 | 估算 |
| 其他 | - | 5% | - | - | - |

**成本曲线:**
- 行业平均毛利率 60%+,头部企业 65%+
- 趋势:**研发投入上升**,但毛利率维持高位

### 2.2 利润层

**毛利分布:**
- 头部动保(科前/生物股份):65%
- 中小动保:40%
- 进口疫苗(勃林格/默沙东):70%+

**溢价能力:**
- 国产疫苗 vs 进口价差 30-50%(成本优势)
- 非洲猪瘟疫苗(待研发)是未来增量

**微笑曲线定位:**
- 本环节位置:**左高(牌照壁垒)**
- 利润正在向 [头部国产动保] 集中

**议价权归属:**
- 谁有提价能力:**科前生物**,原因(市场份额 + 研发)
- 谁在被动接受价格:**中小动保**,原因(产品同质化)
- 涨价能否传导:**能传导 70%+**(刚需)

### 2.3 瓶颈层
**卡点:**
- 牌照:**疫苗生产牌照强约束**,新进入者难
- 研发:**非洲猪瘟疫苗**研发是世界难题
- 客户:大型养殖场(牧原/温氏)议价权强

**定价权归属:**
- **科前生物** 掌握 [猪用疫苗] 定价权,原因:市场份额 30% + 研发投入大
- **生物股份** 在口蹄疫疫苗有优势

### 2.4 供需验证
- 供给:行业产能基本满足,但非洲猪瘟疫苗仍缺
- 需求:年市场规模 [约 200 亿元],稳定增长
- 缺口/富余:**非洲猪瘟疫苗是关键缺口**

### 2.5 价值量定位
- ⭐ **价值集聚(牌照壁垒 + 研发驱动)**
- 一句话定位:"疫苗牌照强约束 + 非洲猪瘟疫苗研发竞赛,动保是猪肉产业链上**最具壁垒的细分**"

### 2.6 反证条件
- 如果 [非洲猪瘟疫苗研发失败],动保企业估值压缩
- 如果 [海外动保巨头大举降价],国产替代溢价消失
- 如果 [非洲猪瘟自然消退],疫苗需求下降

## 跨环节传导分析

### 假设 1:非洲猪瘟再次大规模爆发
- 传导路径:疫情 → 存栏下降 → 猪价上涨 → 养殖盈利改善
- 各环节影响:养殖龙头受益(牧原);种猪企业受益(自给);动保受益(疫苗需求);屠宰短期受损
- 终局:**养殖 + 种猪 + 动保三龙头受益**

### 假设 2:种业振兴政策加码
- 传导路径:政策 → 育种投入加大 → 国产种猪市占率提升
- 各环节影响:育种龙头(牧原/温氏)直接受益;饲料企业间接受益(成本下降)
- 终局:**种猪育种企业估值提升**

### 假设 3:猪周期反转不及预期
- 传导路径:产能去化缓慢 → 猪价持续低迷 → 养殖亏损
- 各环节影响:养殖企业受损(全行业亏损);种猪企业短期受损(需求下降);动保相对稳定
- 终局:**养殖 + 种猪承压,动保相对独立**

### 假设 4:饲料原料(豆粕)价格暴涨
- 传导路径:豆粕涨价 → 饲料成本上升 → 养殖盈利压缩
- 各环节影响:养殖受损;海大/大北农(饲料)间接受益(转嫁成本)
- 终局:**养殖端承压最重**
